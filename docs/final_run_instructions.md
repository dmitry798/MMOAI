# Последний полный прогон: порядок

1. Открыть `notebooks/sp500_coursework_reviewed.ipynb`.
2. Выбрать окружение с пакетами исследования (использовавшийся `bz` допустим).
3. **Restart Kernel**, затем **Run All**. Не выполнять ячейки выборочно поверх
   переменных прежней версии: изменены статистический протокол и формат артефактов.
4. До обучения должны пройти preflight окружения/записиCSV и data/factor checks.
   Все котировки/факторы уже локально; Run All не требует сетевых запросов.
5. Дождаться последней сводки и `run_completed.json` в
   `data/derived/review_strict_2026_11_01/`. Именно этот каталог содержит новый
   научный прогон. Старые `review_2026_11_01` и smoke не смешивать с ним.

## Что изменилось для запуска

- Библиотека parquet больше не требуется: прогнозы сохраняются в CSV.gz.
- SHA256 читается блоками, без зависимости от hashlib.file_digest.
- ФактическийPython,версии и sourceSHA сохраняются в environment.json.
- Данные заморожены по SHA; изменение источников под тем же snapshot вызывает
  раннюю ошибку. Для новой версии данных нужен новый DATA_VERSION/каталог.
- Факторы RF/FF5/Mom загружены в `data/versions/french_factors_review_2026_11_01`.
- Старый выполненный notebook/таблицы находятся в `reports/review_before_strict_20261101`.

В конфигурации сохранён ранее выбранный `REQUIRE_FULL_QUOTES=False`:
доступны495/502 истории. Полнота не скрывается. При True расчёт остановится
до обучения, пока не будут получены семь отсутствующих историй.
Строгость статистики не означает, что вселенная стала полной.

## Таблицы для статьи

- `primary_economic_comparison.csv`: CAPM/FF alpha,HAC,beta,IR,Sharpe,MDD,PF,оборот.
- `scheme_all_metrics_significance.csv`: форма окна/обновление, все метрики и длиныблока.
- `individual_metrics_significance.csv`: индивидуальная значимость базовых и stressed стратегий.
- `overlapping_horizon_all_metrics.csv`: парный опыт hold21−hold10 на общих датах.
- `commission_stress.csv`, `commission_significance.csv`: издержки1/3/5x и их тесты.
- `significance_tests.csv`, `auc_vs_random_tests.csv`: алгоритмы и AUCvs.5.
- `anova_bh.csv`, `feature_date_block_tests.csv`: ANOVA/BH и зависимый bootstrap/BH/BY.
- `coverage_funnel.csv`, `model_eligibility.csv`, `recovered_download_manifest.csv`: данные.

`primary_block=True` обозначает заранее выбранный блок21. Остальные блоки —
проверка чувствительности; выбирать наиболее удачное p-value нельзя.
Решение о значимости после множественности определяется p_Holm. Интервалы
номинальные; сырые p и CI согласованы инверсией одного теста. Если
status=not_estimable, соответствующий вывод о значимости не делается.

Полный прогон может быть долгим: сохранены исходные 273 признака и модели,
включая точный KNN, CV и повторное обучение. FLAML сохраняет wall-clock бюджет;
его найденная конфигурация может зависеть от скорости оборудования даже при
том же seed. Нельзя обещать, что любой внешний kernel/диск/пакет никогда не
даст сбой. Пройденные preflight и smoke уменьшают риск, но не заменяют
завершение именно полного прогона на выбранном окружении.

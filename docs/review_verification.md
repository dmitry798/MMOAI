## Границы проверки

Сквозной прогон проверяет выполнение и согласованность расчётов при уменьшенных моделях; он не заменяет обучение всех моделей на всей доступной панели. Статистическая значимость будет установлена только по таблицам полного прогона. Старый OOS уже просмотрен, поэтому оценка ретроспективная. Bootstrap условен на полученных прогнозах и не включает повторное обучение внутри каждой реплики.

Редакторские замечания к статье перечислены отдельно; PDF не отредактированы. Снимок состава не становится point-in-time выборкой. Результаты на ценах без дивидендов не следует выдавать за полную доходность инвестора.

Предыдущая выполненная тетрадь, метрики и документация сохранены в `reports/review_before_strict_20261101/`. Новые результаты будут в `data/derived/review_strict_2026_11_01/`.
